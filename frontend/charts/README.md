# Isolated Bklit research charts

The dashboard remains static HTML/CSS/JavaScript. Only `.bklit-chart` nodes own React roots. Scanner DOM and state never enter React.

From this directory:

```powershell
npm.cmd ci --no-audit --no-fund
npm.cmd run build
```

The committed `../assets/charts.js` and `charts.css` work without npm, a build server, or runtime CDNs. Build dependencies are pinned in `package-lock.json`.

Upstream chart sources are the dependency closure of BarChart, Bar, BarXAxis, YAxis, Grid and ChartTooltip. Exact repository revision and copied files are in `vendor/bklit/PROVENANCE.json`. BarChart adds `valueDomain`, enforcing percentage axes of 0–100, and uses a small container measurement adapter in place of ParentSize. That adapter prevents zero-height charts after hidden-panel navigation and screenshot viewport changes. Other quantity axes start at zero. Null values have no bar and remain N/A in the numeric ledger. Zero values have zero bar height.

The wrapper disables bar reveal animation, bounds dense category labels, provides aggregate-only tooltips and numerical ledgers, and mounts charts only while their panel is visible. This prevents stale dimensions when static sections are hidden. No benchmark is regenerated by this code.

The Bklit chart source is MIT licensed; the proprietary Studio is excluded. Bklit and dependency licenses accompany the distributed bundle in `../assets/BKLIT-LICENSE.txt` and `THIRD-PARTY-NOTICES.txt`. No external fonts or images are required.

`visual-qa.mjs` runs against the independent loopback dashboard on port 8788 using installed Chrome through Playwright. It captures 1920×1080, 1600×900, 1366×768, and 390×844. This is development browser verification; it does not send a live provider request or run a local model.
