Matching allocationOne-to-one maximum cardinality
Whole template/topic families stay in one split. Some CSV/config families occur only in development. Shared formats, English-heavy text and detector-aware authorship limit generalization.
Metric definitions
PrecisionTP / (TP + FP)
RecallTP / (TP + FN)
F12TP / (2TP + FP + FN)
False-positive rateFP / (FP + TN)
False-negative rateFN / (FN + TP)
Zero denominators are undefined. Span TN/FPR have no finite negative universe; occurrence FPR uses prompts. Recall is not accuracy or a probability of protection.
